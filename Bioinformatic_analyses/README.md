# Bioinformatic analyses of dCas12f Proteins

This repository contains the computational pipeline used to identify guide RNA (gRNA) sequences and their putative genomic targets for domesticated Cas12f (dCas12f) proteins, as described in [Citation].

## Note 1

*This code is not meant to represent a traditional program. Instead, it reflects custom R code used for the bioinformatic analyses in Hoffmann et al (2025).
The script includes both R language code and command line code (in comments), and should be run in Rstudio line-by-line with the Run function.*

## Note 2

**Accompanying input data should be downloaded from: https://drive.google.com/drive/folders/1R7MuxpKOd3Azzx2b4H5uE4NaR2dgJ6UB?usp=drive_link**

## Overview

The pipeline performs:
1. Downloading and processing genomes encoding dCas12f homologs
2. Identifying gRNA scaffold sequences using covariance models (CM)
3. BLASTing guide sequences against host genomes to find targets
4. Filtering putative targets to intergenic regions
5. Annotating target loci using Bakta and PFAM HMM searches
6. Identifying ncRNA elements associated with target loci
7. Categorizing targets by predicted function
8. TAM (Target Adjacent Motif) determination

## Input File Format Specifications

### final_homologs.v2.tsv
Tab-separated file with columns:
- `assembly`: GenBank assembly accession (e.g., GCA_XXXXXXXXX.X)
- `gen.acc`: Genomic accession number
- `start`: Gene start position
- `end`: Gene end position
- `strand`: Strand (+/-)
- `seq`: Protein sequence
- Additional metadata columns as needed

### Bacterial_genome_metadata.genbank.tsv
Tab-separated file with columns:
- `assembly_accession`: GenBank assembly accession
- `assembly_level`: Assembly quality (e.g., "Complete Genome", "Chromosome")
- `genome_rep`: Genome representation (e.g., "Full")
- Additional columns from NCBI assembly_summary files

## Usage

1. **Configure paths**: Edit the CONFIGURATION section at the top of `Hoffmann_et_al_2025_Bioinformatics.R` to set:
   - Working directory
   - Path to Pfam database
   - Path to Pfam clans file
   - (Optional) NCBI API key

2. **Prepare input files**: Place all required input files in the `input_data/` directory.
	- Download from: https://drive.google.com/drive/folders/1R7MuxpKOd3Azzx2b4H5uE4NaR2dgJ6UB?usp=sharing

3. **Run the pipeline**: Execute sections sequentially in R/RStudio. Each major section clears the R environment, so run sections in order.

4. **External commands**: Command-line tools (Infernal, MMseqs2, HMMER, etc.) should be run separately as indicated by the commented-out commands in the script.

## Notes

- The pipeline requires an NCBI Entrez API key for efficient genome downloads. Register at https://www.ncbi.nlm.nih.gov/account/settings/
- Bakta annotation is computationally intensive; consider running on a compute cluster
- Some steps involve manual curation (noted in comments)
- The script is designed to be run interactively, with sections executed sequentially
